🏥 PMH Editor Testing Guide

⚠️ Prerequisites: Make sure your dev server is running on http://localhost:5001
🔍 Where to Find PMH Editor
  • Navigate to Review of Systems page
  • Look for "Past Medical History" section
  • Should see the new editor with chips at the top
⌨️ Keyboard Shortcuts Test
  • Enter Test: Type "Hypertension" → Press Enter
    Expected: New line with proper spacing
  • Tab Indent: At start of line → Press Tab
    Expected: 4-space indentation
  • Tab Autocomplete: Type "htn" → Press Tab
    Expected: Autocomplete popup showing "Hypertension"
  • Space Expansion: Type "dm " (with space)
    Expected: Auto-expands to "Diabetes mellitus "
🔘 Quick Insert Chips
  • Click any blue chip button (e.g., "Hypertension")
  • Expected: Condition inserted at cursor position
  • Try clicking multiple chips
  • Expected: Each appears on new line
📋 Preview & Copy Test
  • Enter some conditions with details (use Tab to indent details)
  • Click "Show Preview" button
  • Expected: Shows numbered EHR format
  • Click "Copy EHR Format"
  • Expected: Formatted text copied to clipboard
📝 Sample Test Data
Try entering this text to test formatting:
Hypertension
    Well controlled on lisinopril 10mg daily
    Last BP reading 125/80 mmHg

Type 2 diabetes mellitus  
    A1C 7.1% (target <7%)
    On metformin 1000mg twice daily
    
Coronary artery disease
    History of NSTEMI 2019
    On dual antiplatelet therapy
    Last echo shows EF 55%
🎤 Transcription Test (if enabled)
  • Look for microphone/transcription button
  • Click to start voice input
  • Say: "Patient has hypertension well controlled"
  • Expected: Text appears at cursor position in PMH editor
🐛 What to Look For
  • ✅ Working: Autocomplete popups, proper indentation, chip insertion
  • ❌ Issues: Console errors, broken shortcuts, missing chips
  • 🔍 Check: Browser console (F12) for any error messages
🎉 Success Criteria:
  • All keyboard shortcuts work as described
  • Chips insert conditions properly
  • Preview shows proper EHR formatting
  • Copy function works
  • No console errors
